
## Goal

Allow a lecturer to create and manage assignments within a course.

## Actors

Actor: API Client

## Entities

- `id`
- `code`
- `title`
- `assignment_status`


## Feature

- create assignments
- retrieve assignments
- update assignments
- delete assignments

## Rules

- `id` is generated by the database.
- `code` is required and unique. max: 10 characters
- `title` is required. max: 255 characters
- `assignment_status` starts with DRAFT


## Business rules

- An assignment with submissions cannot be deleted
- When an assignment is deleted, its test cases are deleted automatically.
- Assignment status cannot be changed through the general PATCH endpoint.

## Basic flow


### Create Assignment

1. The client sends a POST request to `/api/courses/{courseId}/assignments`.
2. The API verifies that the course exists.
3. The API validates `code` and `title`.
4. The API checks that the code is unique within the course.
5. The API creates the assignment with status `DRAFT`.
6. The API returns the created assignment.

### List assignments for a course

1. The client sends a GET request to `/api/courses/{courseId}/assignments`.
2. The API retrieves all assignments of this course.
3. The API returns all assignments of this course.


- If the course has no assignments, return an empty list with 200 OK.
### Fetch Single Assignment

1. The client sends a GET request to `/api/assignments/{assignmentId}`.
2. The API searches for the assignment.
3. The API returns the assignment.


### Update Assignment

1. The client sends a PATCH request to `/api/assignments/{assignmentId}`.
2. The API searches for the assignment.
3. The API validates the supplied fields.i
4. The API updates the assignment.
5. The API returns the updated assignment.

- If the updated code conflicts with another assignment in the course, return 409 Conflict.

### Delete Assignment

1. The client sends a DELETE request to `/api/assignments/{assignmentId}`.
2. The API searches for the assignment.
3. The API deletes the assignment.
4. The API returns 204 No Content.

- If deletion fails, return a server error.
- If the assignment has submissions, return 409 Conflict when deletion is requested.

## Failure flows

- If code is missing, return a validation error.
- If code already exists, return a conflict error.
- If the request body is malformed, return a bad-request error.
- If saving fails, return a server error.
- If the course does not exist, return a not-found error.
- API returns 404 Not Found when an assignment ID does not exist
- If a PATCH request contains no supported fields, return a validation error.



## Endpoints

POST /api/courses/{courseId}/assignments
GET  /api/courses/{courseId}/assignments
GET  /api/assignments/{assignmentId}
PATCH /api/assignments/{assignmentId}
DELETE /api/assignments/{assignmentId}
